# OpenKaiwu · 开物

**Open-source tools for real-world problems.**

OpenKaiwu is an open-source organization dedicated to building useful,
simple, and sustainable tools for everyday life and work.

我们希望持续创造真正有用的开源工具，用软件解决生活和工作中遇到的实际问题。

## What We Build

We build open-source tools for:

- Productivity
- Development
- Research
- Data processing
- Everyday utilities
- AI-powered tools
